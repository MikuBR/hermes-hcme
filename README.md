# Hermes Context & Memory Engine (HCME)

Persistent, context-aware, experiential memory and context management engine for Hermes Agent.

## Status

> **Architecture / Research Phase**
> Nenhuma funcionalidade listada abaixo está implementada neste repositório nesta etapa.

## Escopo pretendido

Este projeto investiga e pretende implementar, futuramente, uma arquitetura para:

- memória persistente;
- memória separada por sessão, projeto e escopo;
- recuperação contextual;
- reconstrução de contexto após múltiplas compactações;
- memória experiencial;
- organização semântica/hierárquica de temas;
- relações entre memórias;
- aprendizado baseado em experiências;
- adaptação comportamental contextual;
- integração com o ContextEngine e Memory interfaces do Hermes;
- futura integração com o sistema `/learn` e Skills;
- futura Experience Factory para testar e fortalecer Skills.

## Repositório

Nesta etapa inicial, o repositório contém apenas documentação-base. Nenhum código de implementação está presente.
